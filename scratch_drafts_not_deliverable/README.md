# پیش‌نویس‌های داخلی – خروجی نهایی نیستند

این پوشه شامل فرگمنت‌های HTML اولیه (U00 تا U03) است که در نشست دوم، پیش از تصمیم «جزوه‌ی نهایی در این مرحله ساخته نشود»، نوشته شد.
- بازبینی نشده و تطبیق بصری کامل ندارند.
- پرچم «نیاز به تأیید» در بعضی بندها باز است.
- هیچ‌کدام مبنای PDF نهایی یا پرامپت نیستند. Agent باید از صفر و از روی منبع (PDF، MD، تصویر صفحه) بسازد.
